# 长生录 / Immortal Path

一款完全离线、单机运行的文字卡片式修仙 Roguelite。玩家会经历一世又一世的修行、突破、衰老与死亡；人物会轮回，世界却会继续演化，最终形成属于自己的修仙史。

## 技术栈

- Vue 3、TypeScript、Vite
- Pinia、Vue Router
- Dexie.js + IndexedDB 本地持久化
- Vitest 核心逻辑测试

项目不包含后端、在线 API、登录或云数据库。依赖安装完成后，游戏运行不需要联网。

## 安装、运行与构建

```bash
npm install
npm run dev
npm test
npm run build
```

## 游戏玩法

1. 选择出身、灵根、五维属性与多个天赋，或分别交给天意随机生成。
2. 第一世选择有限；后续转世可在轮回殿购买下一世的择命权限。
3. 修炼一月、三月、一年或闭关三年、十年，游戏会即时模拟时间与世界变化。
4. 修炼期间可能触发数据驱动的随机奇遇；历练可获得境界奖池物品并积累掉落保底。
5. 修为达到要求后手动突破。成功会进入下一境界并提高寿元，失败可能倒退、折寿甚至死亡。
6. 死亡后查看完整生平，并选择接管存活的成年后代，或进入轮回殿重新投胎。
7. 人物可以更替，但世界年份、宗门状态、旧家族、旧后代和世界历史不会重置。

开发模式可在“设置 → 天道调试台”快速增加资源、生成后代、解锁天赋、查看隐藏身世或进入轮回殿。

## 项目结构

```text
src/
├─ core/          # 修炼、创建、突破、掉落、轮回、时间、世界、随机与存档规则
├─ data/          # 境界、物品、天赋、出身、灵根、事件与掉落表
├─ models/        # TypeScript 领域模型
├─ stores/        # Pinia 流程协调与自动保存
├─ components/    # 角色创建、角色状态、最近纪事与奇遇选择
├─ views/         # 八个路由页面
└─ router/        # Hash 路由，兼容本地静态运行
```

## 核心系统

- 时间以月为内部单位，界面展示年/月；没有现实倒计时。
- 23 个境界覆盖凡人、炼气 1—10 层、筑基/金丹/元婴四阶段。
- 30 个随机事件、22 件物品、22 个分级天赋与 8 种出身均为配置驱动。
- 掉落由境界奖池、气运权重、福缘模式与稀有/极品双保底共同决定。
- 世界模拟会在时间流逝时生成大事、改变宗门势力并推进非玩家后代年龄。

## 第二阶段：择命与血脉

- 第一世开放五种凡俗出身，可手选五、四、三、双灵根和十五种基础天赋；随机灵根仍可能获得稀有品质或变异属性。
- 每个出身分别定义基础属性、属性上限、自由属性点、初始资源与玩法修正；天赋点使用独立配置。
- 天赋点允许搭配任意数量的合法天赋；随机天赋获得一点额外价值预算。
- 后代由父辈属性、遗传权重、随机波动与血脉共同生成，并作为真实世界人物保存。
- 血脉延续会接管既有后代，不能重新捏人，但会继承部分家族灵石、物品和血脉标记。
- 轮回点用于购买下一世的天赋预算、属性上限、高阶天赋/灵根/出身权限和前世记忆，不再永久线性增加属性。
- 高级天赋同时受下一世选择权限和永久因果条件限制。

### V2.1 属性与灵根修订

- 出身只影响基础属性、潜力、自由属性点、初始资源与特殊修正；天赋预算改为独立配置。
- 第一世自由属性点为：农户 50、猎户 45、商贾 35、书香门第 35、神秘弃婴 45。
- 灵根数量表示广度与总吸收效率，品质和变异表示专精方向，不再使用线性品阶。五灵根总修炼效率 ×1.35，四灵根 ×1.27，三灵根 ×1.18，双灵根 ×1.10，单灵根 ×1.00；灵根越少，同系功法专精越高。
- 灵根补偿自由属性点为：五灵根 +0、四灵根 +1、三灵根 +3、双灵根 +5、单灵根 +6。
- 雷、冰、风、暗、光是可组成单/多灵根的变异元素；`PURE` 与 `HEAVENLY` 是品质。极稀有的五行天灵根总修炼效率为 ×1.60。
- 第一世手选仅限标准五行的五、四、三、双灵根；后世可分别解锁单灵根、变异元素、纯净与天品品质。随机生成不受这些手选权限限制。
- 功法契合与大境界突破分别通过统一的灵根契合度、突破修正接口计算。
- 角色新增 `statPotential` 和带时间、原因的 `statHistory`；奇遇、突破、失败与衰老统一通过属性修改机制处理。
- 普通成长受潜力限制，明确标记的特殊效果可以突破潜力。

## 存档说明

主存档位于浏览器 IndexedDB 的 `immortal-path-db` 数据库。修炼、历练、突破、事件、死亡与轮回选择后会防抖自动保存；设置页支持立即保存、导出 JSON、导入 JSON与删除重开。

产品版本为 V2.1，内部存档结构版本已升级至 4：

- Dexie 在打开数据库时迁移 V1 IndexedDB 主存档。
- 导入旧 JSON 时使用相同的兼容归一化流程。
- V1 角色、人物志与世界历史会保留。
- V1 已购买的永久属性等级会折算为轮回点补偿。
- V1/V2/V3 的旧 `rank` 灵根会转换为元素、品质、总修炼效率、专精效率与突破修正；旧天灵根和异灵根也会归一化。
- 旧版混用的稀有计数会迁移为稀有掉落计数；V4 起稀有事件与稀有掉落分别记录。

## 尚未实现

本阶段只建立家族、血脉和后代的基础架构，尚未实现婚配、完整家族经营、家族功法/法宝、复杂 NPC 行为、宗门、炼丹、商城、天气、AI 或在线功能。这些能力留待后续阶段，不属于当前版本。
