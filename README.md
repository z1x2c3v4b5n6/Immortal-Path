# 长生录 / Immortal Path

一款完全离线、单机运行的文字卡片式修仙 Roguelite。玩家会经历一世又一世的修行、突破、衰老与死亡；人物会轮回，世界却会继续演化，最终形成属于自己的修仙史。

## 技术栈

- Vue 3、TypeScript、Vite
- Pinia、Vue Router
- Dexie.js + IndexedDB 本地持久化
- Vitest 核心逻辑测试

项目不包含后端、在线 API、登录或云数据库。依赖安装完成后，游戏运行不需要联网。

## 安装与运行

```bash
npm install
npm run dev
```

浏览器会显示 Vite 提供的本地地址。生产构建：

```bash
npm run build
```

运行测试：

```bash
npm test
```

## 游戏玩法

1. 为第一世角色取名，随机获得出身、灵根和一至两个天赋。
2. 选择修炼一月、三月、一年或闭关三年、十年，游戏会即时模拟经过的时间。
3. 修炼期间可能触发数据驱动的随机奇遇；不同选择产生不同结果。
4. 外出历练可获得灵石和按境界奖池生成的物品，并积累掉落保底。
5. 修为达到要求后手动尝试突破。成功进入下一境界并提升寿元，失败则可能倒退、折寿，甚至身死道消。
6. 寿元耗尽后查看完整生平、获得轮回点，在永久道果中做有限升级，再开启下一世。
7. 新人物出生时，世界年份、宗门状态和世界大事会延续，而非重置。

开发模式可在“设置 → 天道调试台”快速增加修为、调整寿元、触发事件或死亡，以验证完整生命周期。

## 项目结构

```text
src/
├─ core/          # 纯规则：修炼、突破、掉落、轮回、时间、世界、随机、存档
├─ data/          # 境界、物品、天赋、出身、30 个事件与掉落表
├─ models/        # 完整 TypeScript 领域模型
├─ stores/        # Pinia 流程协调与自动保存
├─ components/    # 角色状态、最近纪事、奇遇选择
├─ views/         # 八个路由页面
└─ router/        # Hash 路由，兼容本地静态部署
```

## 核心系统

- 时间以月为内部单位，界面展示年/月；没有现实倒计时。
- 23 个 V1 境界覆盖凡人、炼气 1—10 层、筑基/金丹/元婴四阶段。
- 30 个随机事件、22 件物品、12 个正负混合天赋、8 种出身均为配置驱动。
- 掉落由境界奖池、气运权重、福缘模式与稀有/极品双保底共同决定。
- 轮回点综合境界、寿数和成就计算；四条永久成长线均有递增成本与等级上限。
- 简化世界模拟会在时间流逝时生成世界事件并改变宗门势力，数据跨世保存。

## 存档说明

主存档位于浏览器 IndexedDB 的 `immortal-path-db` 数据库。修炼、历练、突破、奇遇选择、死亡与轮回升级后会进行防抖自动保存。设置页支持立即保存、导出 JSON、导入 JSON、删除存档和重新开始。`localStorage` 不承担游戏存档。
